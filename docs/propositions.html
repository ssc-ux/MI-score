Ponte C et al. 2022 ACR/EULAR classification criteria for giant cell arteritis. Ann Rheum Dis 2022;81:1647-53. Critères de classification : ils ne servent pas à poser le diagnostic.

Règles médicales, fonctionnalités, technique

Pièges à éviter

  • Critères d'entrée bloquants : AAN ≥ 1:80 pour le LES, âge ≥ 50 ans pour l'ACG. Ils sont vérifiés avant tout calcul.
  • Pondéré ou compté : le LES 2019 et le SAPL 2023 retiennent le poids maximal par domaine. Yamaguchi exige ≥ 5 critères dont ≥ 2 majeurs.
  • Unités SI et conversions (créatinine du PLASMIC, ferritine). Le HScore donne une probabilité.
  • Versions datées, les anciennes restent consultables, jamais mélangées. « Non évalué » ≠ « absent ».
  • Bandeau sur chaque fiche : une classification ne pose pas le diagnostic. Aucune donnée patient n'est stockée.

Ce qui démarque le site

  • Texte pour le courrier : score, items positifs, version et référence, copiés en un geste.
  • Critères manquants : fourchette atteignable et examens à demander pour conclure.
  • Lien partageable qui contient les réponses, pour la RCP, sans serveur.
  • Favoris et récents disponibles hors ligne (PWA).
  • Fiche source : population de validation, Se/Sp, date de dernière relecture, relecteur.

Socle commun avec CorticoPlan

  • Stack identique : Svelte 5, Vite, TypeScript, Vitest, GitHub Pages, service worker.
  • Un seul moteur : un composant Calculateur affiche tous les outils à partir de fichiers JSON (oui/non, choix, nombre avec paliers, max par domaine, entrée, seuils).
  • Tests : chaque JSON contient des cas tirés de l'article d'origine, rejoués à chaque build.
  • Partage du style : on commence par une copie, puis on extrait un package @ssc-ux/socle (tokens, EnTete, Tuiles, thème, sw.js) quand un troisième site arrive.

À corriger dans CorticoPlan avant d'extraire le socle

  • Le bloc sombre automatique est dupliqué (--pnds, --s1…8), et le sombre forcé ne redéfinit pas ces variables.
  • Deux vocabulaires d'alias coexistent (--fond/--card, --bord/--line) : n'en garder qu'un. Renommer --pnds en --succes.
  • La police Google n'est pas mise en cache hors ligne : l'héberger avec le site.
  • Le cache corticoplan-v1 n'est jamais versionné ni nettoyé. La theme-color reste fixe en mode sombre.
